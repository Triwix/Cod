# Independent audit — build 26 (November 10, 2026)

Audit of Codex's work by Claude. No code was changed during the audit.

- **Read line by line (~3,300 of ~12,900 Swift lines):**
  - PiP controller
  - Capture coordinator
  - Root view and every entry point (Shortcuts, Share extension, files, URL)
  - Share handoff store
  - Library store
  - Timer alarms
  - Image decoding
- **Checked across all app and extension sources:**

  - Info.plists, entitlements and privacy manifests
- **Ran:**
  - Full unit suite: **248/248 pass**, Xcode 27.2, iPhone 17 Pro Max simulator, iOS 26.5.
  - `Tools/verify-supported-source.sh`: passes, once a ripgrep binary is on PATH (see M1).

  - Settings, Library and the tool editor views.
  - UI test suite.
  - Physical PiP, iPad, and iOS 17/18 (see M2).

## Overall

The core is careful work. PiP start/replace/restore, request cancellation,
storage recovery, and share/notification handoff all guard against stale or
out-of-order events. Logging is debug-only. Privacy manifests match the APIs
used. No private APIs were found, and there's one `fatalError`, in an unused
initializer. Most of the risk is in the two user-facing issues below, not in
crashes.

## High — fix before 1.0

Both fixed in build 27; see [share-resolution-27.md](share-resolution-27.md).

**H1. Images from Shortcuts and the Share sheet are shrunk to 2048 px on the long side.**
- **Where:**
  - `UIImage.decodedImage(data:maximumEdge: 2_048)` in [ImageProcessing.swift:6](../Cod/Capture/ImageProcessing.swift)
  - Crop With Cod and Float With Cod ([CodIntents.swift:122](../Cod/Intents/CodIntents.swift), [:190](../Cod/Intents/CodIntents.swift))
  - The Share extension ([ShareViewController.swift:156, 188](../CodShare/ShareViewController.swift))
- **Effect:** an iPhone 16 Pro Max screenshot (1320 × 2868) becomes about
  943 × 2048, roughly half the pixels. Crops of small text get blurrier, OCR
  gets worse, and saved crops are lower resolution. The in-app Photos path
  keeps full resolution, so the same screenshot behaves differently depending
  on how it arrived. This hits the Back Tap → Crop With Cod flow the listing
  leads with.
- **Fix:** use a much larger limit for intents, which run in the app with a
  normal memory budget. Raise the extension's limit to at least
  native-screenshot size; screenshots are small compared with camera photos.

**H2. Sharing to Cod's app icon closes the sheet without saying what to do next.**
- **Where:** [ShareViewController.swift:254–266](../CodShare/ShareViewController.swift).
  With the default setting (notifications off), the extension shows
  "Preparing image…", saves the image and dismisses itself.
- **Effect:** the user and the App Review reviewer see the share sheet vanish
  with nothing floating. Nothing tells them to open Cod. The "Image ready —
  open Cod" screen already exists, but it only shows when a notification
  fails.
- **Fix:** end on that ready screen with a Done button instead of
  auto-dismissing.

## Medium

**M1. The source policy check can't run on this Mac as written.**
[verify-supported-source.sh:6](../Tools/verify-supported-source.sh) requires
`rg` (ripgrep), which isn't installed. Codex had its own copy, so this never
surfaced. Fix: switch it to `grep`, like the build-23 store verifier, or
document `brew install ripgrep`.

**M2. iOS 17/18 launch checks can't be run with this toolchain yet.**
Xcode 27.2's downloader doesn't offer iOS 17.x or 18.x simulator runtimes. It
answered "not available for download" for 18.6, 18.5, 17.5 and their build
numbers. Options:
- (a) Download the iOS 18 and 17 simulator runtime DMGs from
  developer.apple.com/download/all (needs your Apple ID). Then
  `xcodebuild -importPlatform` them.
- (b) Raise the minimum to iOS 18. This removes the iOS 17 gate; the controls
  already need 18.
- (c) Borrow a device on iOS 17/18, which also covers PiP.

## Low — after 1.0

- **L1.** OCR defaults to English only (`ocrLanguages = ["en-US"]`,
  [AppSettings.swift:92](../Cod/Store/AppSettings.swift)). Other languages
  recognize poorly unless the user changes Settings. Consider automatic
  language detection before selling outside English-speaking markets.
- **L2.** Compiler warning at [PiPPinController.swift:371](../Cod/Pins/PiPPinController.swift):
  the video float task holds a strong reference to the controller. It's
  harmless because the controller is a singleton, and a one-line fix.
- **L3.** Dead code: the `cod-store://float-shared-image` URL handler
  ([RootView.swift:72](../Cod/App/RootView.swift)) has no remaining sender now
  that the extension can't launch the app. It's harmless, since it only
  claims the user's own pending share by exact ID.
- **L4.** Share preferences live in the keychain, from the free-team era
  before App Groups. Keychain items survive deleting the app, so a reinstall
  keeps old share settings. They could move to App Group defaults.
- **L5.** The README and APP_STORE_RELEASE.md are 26 builds of changelog. The
  current state is hard to find, so trim them after launch.
